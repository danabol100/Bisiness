# Business Landing Page

## 📌 Project Description

This project is a business landing page built from a design mockup.
It represents a modern website for a company or agency offering services.

The main goal of the project is to practice responsive layout, clean UI structure, and basic interactivity using JavaScript.

## 🚀 Demo

👉 https://danabol100.github.io/Bisiness/

## 🛠 Technologies Used

* HTML5
* CSS3 / SCSS
* JavaScript (Vanilla JS)

## 📱 Features

* Fully responsive layout (desktop / tablet / mobile)
* Modern and clean business UI
* Structured content sections (services, about, contact, etc.)
* Interactive elements (navigation, buttons, hover effects)

## 🎯 Project Highlights

* Built from a design mockup
* Focus on clean and readable code
* Responsive design implementation
* Reusable and organized styles

## 📂 Project Structure

* /css — styles
* /js — scripts
* /img — images
* index.html — main page

## 🛠 Installation and Setup

1. Clone the repository:
   git clone https://github.com/danabol100/Bisiness.git

2. Open the index.html file in your browser
